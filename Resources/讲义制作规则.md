# 高三英语「备课讲义版」生成规则（已固化）

> 适用：把【考卷】+【答案】+《标准模式讲义》三份 docx 合成为一份可直接下发的 Word 讲义。
> 本文件是历次修改意见的汇总，后续新增意见一律追加到文末「变更日志」，并按最新规则执行。

---

## 0. 交付方式

- **直接输出 .docx 文件**交给用户下载，**不要在对话里贴正文**。
- **不做格式自检**，只关注内容本身；生成后仅做一次轻量结构校验（能否打开、段落数、颜色是否写入）。
- 文件名默认：`<学校><学年><学期>高三英语<月份>周练（备课讲义版）.docx`，保存在会话工作区根目录。
- 文件属性判断：三份输入文件命名不一定对应，须**按内容判断**哪个是考卷、哪个是答案、哪个是标准模式（考卷与答案也可能在同一文件内）。

## 1. 全局排版（照搬《标准模式讲义》）

| 项目 | 取值 |
|---|---|
| 页面 | 12240×15840 twips（Letter） |
| 页边距 | 上下 1080 twips（0.75"），左右 1152 twips（0.8"） |
| 中文字体 | 全文**宋体**（SimSun）；**最大标题用黑体**（SimHei） |
| 英文字体 | 全文 **Times New Roman**（ascii/hAnsi/cs 均设，eastAsia 单设） |
| 行距 | 1.15（standard 的 w:line=276） |
| 段前/段后 | 正文 60/20 twips 级；标题更大，见下 |

### 字号与颜色（run 类型表）

| kind | 中文含义 | 颜色 | 加粗 | 下划线 | 半磅值(字号) |
|---|---|---|---|---|---|
| `title` | 文件主标题（**黑体**） | `104B90` | ✔ | | 30（15pt） |
| `h1` | 一级标题（II. Grammar…） | `104B90` | ✔ | | 26（13pt） |
| `h2` | 二级标题（Section A…） | `104B90` | ✔ | | 23（11.5pt） |
| `pt` | 篇章标题（居中） | `000000` | ✔ | | 23 |
| `l` / `l20` | 【标签】如【参考译文】 | `104B90` | ✔ | | 21 / 20 |
| `n` | 正文、原文 | `000000` | | | 21（五号） |
| `b` | 题干、加粗句 | `000000` | ✔ | | 21 |
| `r` | **正确答案（填进空格）** | `C00000` | ✔ | ✔ | 21 |
| `ru` | **正确答案（选项/译文）** | `C00000` | ✔ | | 21 |

> 颜色三位一体固定：**红=C00000 正确答案、紫=7030A0 干扰项、绿=008040 解析、墨绿=104B90 标题与标签**。凡"同类情形"一律沿用这套配色。

### 首行缩进规则（重点）

- **只有原卷中真正的段落首行才缩进 2 字符**（`Pt(21)`）。
- 因插入答案解析而**被强行断开的续段不缩进**。
- 下列一律不缩进：Directions、章节标题、篇章标题、题干与选项、【本节答案速查】、思路精析、选项池/参考池、表格、参考答案标签行。
- 独立成篇的范文段落（Summary 官方范文、写作高分范文）按"独立段落"处理，**缩进**。

### 同页规则（重点）

- **禁止使用 `keepNext` / `keepLines`**：Word/WPS 会在段落左侧显示一个**黑色方块标记**（用户明确要求不得出现）。
- 改为靠版式本身解决：完形填空采用**句子级短块**（含空句 + 该题选项 + 解析 ≈ 6–9 行），短块自然分页，既不产生大片空白，也基本不会把填空与选项拆开。
- 若个别位置仍被分页拆开，优先压缩行距/段前段后；仍不行再用**单行无框表格（行设 cantSplit）**包裹该题块——表格行不会产生黑色方块标记。
- 全文不添加任何编号/项目符号（`w:numPr` 计数必须为 0）。注意：黑方块**不是**编号，而是 keep 标记。

## 2. 各大题处理规则

### 2.1 通用

- 每个**选择题/填空题**大题（Section）之前加【本节答案速查】，标签 `104B90` 加粗，答案 `C00000` 加粗。
  例：`【本节答案速查】 21-25: C A B A D   26-30: …`；六选四另标 `[干扰项：B、C]`；选词填空另标 `[多余项：B. previously]`。
- **所有原始题干与备选答案必须保留**（Directions、篇章、题目、选项、分值说明、原卷的选项框等）。
- 试卷原有的大题编号（如 "VI. Guided Writing"）**照原卷写**，不擅自改写。

### 2.2 语法与词汇（填空形式，Section A）

- 参照标准模式：**保留下划线**以模仿空格。
- 每个空：红字加粗下划线**正确答案** → 紧跟绿字 `(所给词) 【语法解析】`（所给词放绿色括注里）。
- 解析要写清"为什么"，句式：`【语法点，…在句中作…，意为"…"】`。
- 原段落整段不动，只嵌入答案与解析。

### 2.3 选词填空（Section B，词库形式）

- 保留【原始备选词汇框】（灰字 `333333`、小五），按原卷词序排列。
- 答案就位：红字下划线，格式为 `X. word 中文义项`。
- 就近插入【就近选项参考池】（墨绿标签 + 灰字内容），每池覆盖相邻几个空；多余项在池末注明"多余未选干扰项"。
- 段落首行仍按"原文段落"缩进。

### 2.4 完形填空（阅读 Section A，ABCD 选择型）

> **一次改定的最终版式：句子级"一空一组"。**

1. 把原文**按句子切开**，每一切口只到"含该空的句子结束"为止：
   `含空原文句（红字下划线答案，格式 = 序号 + 字母. 单词，如 "21 C. booming"）`
   → 紧接下一段 `【第 N 题】` + **A B C D 原顺序**四个选项（各带括号中文翻译），正确项红字加★，干扰项紫色
   → 紧接绿字 `思路精析：…`
   → 再继续下一句原文。
2. **填空内答案只要"字母 + 单词"，不要中文翻译**（翻译在下面选项里）。
3. **选项顺序必须 A→B→C→D**，不得把正确项提到最前（影响阅读）。
4. **绝不能把一个段落的多个空攒在一起列选项**——那样选项会挤成一团。
5. 原卷末尾汇总的 21–35 选项列表**删除**（题干可被打散在段落内）。
6. 只对**原段落首行**保留缩进；被切开后的承接句不缩进。段末无空的剩余句子完整保留。

### 2.5 阅读理解（Section B，选择题）

- 红字加粗 = 正确答案，紫色 = 干扰项；正确项后加 `[正确答案]`。
- 每个选项组后紧跟绿字 `【解析定位】 题型 + 定位段句 + 排除理由 + 故选 X。`
- 在**原文内**以绿字加粗 `[36D …]` 形式标注该题答案出处，并用**加粗**突出关键句；能逐句对应就逐句对应。
- 篇章内的括号中文注释（如 `(驱逐)`）保留。
- 原文中的表格（如博客评论区）用 `Table Grid` 表格原样保留。

### 2.6 六选四阅读填空（Section C）

- 题干后紧跟【选项池解析与标注】：**选项池按 A、B、C、D、E、F 字母顺序**排列（不按答案顺序），正确项红字、干扰项紫色；每项附 `译文：…` 与 `备课精注：对应N空…`（绿字）；干扰项标注【干扰项：…】。
- 正文原空处按填入答案：红字下划线 `【F】 原句 （中文译文）`，后接绿字【备课衔接：…】说明前后如何衔接。

### 2.7 Summary 写作

- 保留原文与 Directions。
- `【官方参考范文】`（墨绿标签）+ 红字范文（答案文件给的范文直接用）。
- `【要点提炼与评分维度解析】`（墨绿标签）+ 绿字分条：核心论点 / 原因或细节 / 语言重组亮点。

### 2.8 翻译

- 逐题保留原句与括号规定词（题干加粗）。
- `【参考译文】`（墨绿标签）+ 红字译文 + 分值 `(3分)`；多解时增列 `【参考译文·替换版】`。
- 绿字 `【分值采分点与考点精析】` + `• 采分点：…` + `• 词汇句法：…`（规定词的搭配、固定句型、易错点）。

### 2.9 Guided Writing

- 保留原题中文要求（`【原题要求】`）。
- `【高分参考范文】`（墨绿标签）+ 范文标题（黑字加粗）+ 范文正文（120–150 词，按题目要求写全要点，段落缩进）。
- `【写作架构与亮点表达赏析】`（墨绿标签）+ 绿字三条：审题立意与行文结构 / 高分地道词汇与短语（`•` 列表 + 中文释义）/ 句式多样性（点名所用从句与修辞，并报字数）。
